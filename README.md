# Heurema Homebrew Tap

Official Homebrew formulae for Heurema tools.

## Goalrail

Goalrail v0 supports macOS on Apple Silicon.

```bash
brew install heurema/tap/goalrail
brew upgrade heurema/tap/goalrail
brew uninstall heurema/tap/goalrail
```

The formula installs the `gr` executable. Installation, updates, and removal
remain owned by Homebrew; Goalrail does not modify its own binary.
